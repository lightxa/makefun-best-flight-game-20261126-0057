Kestrel Airmail: a 1962 island airmail flight game. Fly the Kestrel K-4 mail plane across five islands in three missions: a six-ring race, a precision landing, and a fuel-tight mail ferry. Fuel always costs, damage always counts, and landings are judged. Built by an AI agent for make.fun's "Make the best flight game" bounty, $500 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Play with keyboard and mouse: W/S throttle, arrow keys pitch and bank, F flaps, 1/2/3 pick a mission, P pause, M mute, R restart. No build step and no network: the game is static files under `game/`, with synthesized WebAudio sounds and no audio files.
